Project Overview

Smart ATM Machine GUI is a simple Java-based desktop application developed using Java Swing.
The application simulates basic ATM operations through a graphical user interface.

Users can:

Check Account Balance
Deposit Money
Withdraw Money
Exit the Application

This project is useful for beginners to understand:

Java GUI Programming
Event Handling
Swing Components
Conditional Statements
Loops and Logic Building

GUI Operations
1. Check Balance

Displays the current account balance.

2. Deposit Money
Enter deposit amount
Balance updates automatically
3. Withdraw Money
Enter withdrawal amount
Checks available balance
Shows error if balance is insufficient
4. Exit

Closes the application safely.
